**Common design DNA to copy:**
1. **KPI strip first** (4–8 big numbers, abbreviated, with delta and/or sparkline, often coloured tiles or icons).
2. **Grid of equal-gap tiles** that fill the screen; no empty plot areas; no scrolling for the main page.
3. **Filters always visible** (top bar or right column), date range slider is the most common.
4. **Mix of chart types** chosen for the job: lines for time, bars for ranking, donut ≤ 6 slices for share, table/matrix with conditional formatting for detail, maps for geography, gauges for target progress, funnels for stages.
5. **Pages/tabs inside the dashboard** (Overview · Agents · Deals).
6. **Minimal text**: titles of 2–5 words, numbers do the talking.
7. **One consistent theme** (palette + font + radius) across every tile; both light and dark versions look premium.

## 2. Power BI research — what to copy (authoring side and viewer side)

Use these Power BI concepts as the functional benchmark:

**Structure**
- A report = **pages**; each page = a **canvas of visuals**. A "dashboard" is a one-screen overview built from pinned visuals. Microsoft's design guidance: tell the story on **one screen without scroll bars**, put the **highest-level data top-left**, use **cards** to make important numbers stand out, avoid clutter, use **full-screen mode** to present.
- Visuals interact by **cross-filtering and cross-highlighting**, can **drill through** to other pages, and are styled by a **report theme** (overridable per visual in the **Format pane**).

**Built-in visual families** (must exist in JT-Code; map the existing 85-chart gallery onto them): bar/column (clustered, stacked, 100%), line, area (stacked), combo (bar + line, dual axis), ribbon, waterfall, pie/donut, treemap, funnel, scatter/bubble/dot plot, table, matrix (pivot with drill), maps (filled/choropleth, bubble), **card / multi-card** (with images and reference values), **KPI** (value vs goal with trend), gauge, goals/scorecard, **AI visuals** (decomposition tree, key influencers, smart narrative / summary, anomaly detection), slicers, image, text box, shapes, buttons, page & bookmark navigators, Python visual, **small multiples**, **report-page tooltips**, **visual calculations** (running total, moving average, % of total, rank), **analytics pane** (constant/average/min/max/median/percentile lines, forecast, anomalies, error bars), **conditional formatting** (background, font colour, data bars, icons, gradient by value, rules).

**Slicer types:** classic slicer (vertical list, tile, dropdown, date picker incl. **relative dates** like "last full month"), **button slicer** (styled grid of buttons with icons/images), **list slicer** (hierarchy, search, conditional formatting), **input slicer** (free text/number with operators: contains, starts with, =, >…), numeric range slider, relative time. Features: single/multi select, **Select all**, search, **paste a list of values**, slicers filter each other, **Sync slicers across pages** (with separate "sync" and "visible" settings and **sync groups**), **Apply all / Clear all slicers** buttons.

**Filters pane:** visual, page and all-pages (report) levels; basic, advanced, Top N; author can lock/hide filters.

**Customization by the author:** on-object editing (double-click a visual → click a part → its format options open), format pane with search, themes (JSON: dataColors, structural colours, text classes, per-visual styles; customize-theme dialog; import/export), canvas size & background/wallpaper, alignment/distribution, selection pane with layers & groups, mobile layout.

**Customization by the viewer (important — "the user chooses how it looks"):**
- **Personalize this visual** (no edit rights needed): change visual type, swap a measure or dimension, add/remove legend, drag fields between wells, reorder table columns, add measures to compare, change aggregation; save as a **personal bookmark** (optionally default view), share with changes, **Reset this visual**, **Reset to default** (whole report), clear recent changes. Author can enable/disable it per report or per visual.
- **Field parameters:** slicer that lets viewers **choose which measure (Revenue/Profit/Units) or which dimension (Country/Product/Channel)** every bound chart uses.
- Personal bookmarks, focus mode, spotlight, show as table, export data, sort.

**AI layer (Copilot style):** create a report page from a prompt ("show revenue by region over time"), **suggest content** for a page, write a **summary/narrative visual** that updates with slicers, answer questions about the data, summarize a page.

**Data preparation (Power Query style):** an **Applied steps** list, column quality bars (valid / error / empty %), column distribution (distinct / unique), column profile with stats and value distribution where you can **right-click a bar to transform/filter that value**, data types, rename, remove, split, merge/append queries, pivot/unpivot, group by, fill, replace values, column-from-examples, conditional columns, date table, relationships between tables.

## 4. Data model

```ts
Dashboard {
  id, name, description?, ownerId, workspaceId, datasetIds[],
  themeId | themeJson, density: "compact"|"comfortable",
  settings { allowPersonalize: bool, showFiltersPane: bool, lockFilters: bool, defaultPageId },
  globalFilters: Filter[], syncedSlicerGroups: SyncGroup[],
  parameters: Parameter[]            // field parameters + what-if parameters
  calculations: Calculation[],       // dashboard-level calculated fields/measures
  bookmarks: Bookmark[],             // author bookmarks
  pages: Page[], createdAt, updatedAt, version
}
Page {
  id, name, order, hidden: bool, type: "page"|"tooltip"|"drillthrough",
  drillthroughFields?: FieldRef[],
  canvas { preset:"16:9"|"4:3"|"letter"|"custom"|"fit-width", width, height, background, wallpaper, padding },
  pageFilters: Filter[], visuals: Visual[], mobileLayout: {visualId, x,y,w,h}[]
}
Visual {
  id, type, title, subtitle?, groupId?, hidden: bool, locked: bool,
  layout { x, y, w, h, z },                       // grid units
  data { datasetId, wells: { category[], values[], legend[], smallMultiples[], tooltips[], secondaryValues[], target[], size[], details[] },
         aggregations, showValueAs, sort, topN, visualCalcs[], filters: Filter[] },
  format { ...per-section overrides of the theme },
  conditionalFormats: Rule[],
  analytics: AnalyticsLine[],
  interactions: { [targetVisualId]: "filter"|"highlight"|"none" },
  drill { hierarchy: FieldRef[], level },
  allowPersonalize: bool, altText
}
PersonalView { userId, dashboardId, visualOverrides{}, slicerState{}, filterState{}, isDefault, name }   // viewer personalization
Bookmark { id, name, scope:"author"|"personal", pageId, state{filters, slicers, visibility, sort, drill, visualOverrides} }
Theme { name, mode:"light"|"dark", dataColors[], good, neutral, bad, structural{canvas, tile, border, gridline, text, mutedText, accent}, textClasses{title, label, callout, header}, radius, shadow, fontFamily, visualStyles{} }
```

- Store in backend tables (`dashboards`, `dashboard_versions`, `personal_views`, `themes`). **Autosave** (debounced 800 ms) + **version history** (restore previous versions) + client **undo/redo** (Ctrl+Z / Ctrl+Y, 50 steps).
- **Migration:** every existing saved chart becomes a `Visual` in a "My visuals" library; every existing report becomes a dashboard (one page, visuals stacked in a 2-column grid) while keeping its HTML/Excel/JSON export.

Right pane is one collapsible pane with tabs (Build · Format · Filters · Selection); it can be pinned or floating. The canvas must get maximum space.

### 6.2 Canvas
- 24-column snap grid, row unit ≈ 24 px (use `react-grid-layout` if React, `vue-grid-layout`/`gridstack.js` otherwise) **plus** a free-position mode for pixel-perfect layouts.
- Drag, resize, duplicate (Ctrl+D), copy/paste between pages and dashboards (Ctrl+C/V), delete, multi-select (Shift/Ctrl, marquee), **group/ungroup**, bring forward/send back.
- **Smart guides** while dragging; toggles: gridlines, snap to grid, lock objects.
- Align (left/centre/right/top/middle/bottom), distribute horizontally/vertically, match width/height.
- Exact X/Y/W/H inputs.
- **Selection pane**: list of all visuals as layers (rename, show/hide 👁, lock 🔒, reorder, groups) — needed for bookmarks that toggle visibility.
- Canvas settings: size preset (16:9 default 1280×720, 4:3, Letter, Custom, Fit-to-width), page background colour/image/transparency, **wallpaper** (area outside the page).
- Zoom: Fit page, Fit width, 50–200 %.
- **Mobile layout** per page: drag visuals into a phone frame (single column); hidden visuals allowed; formatting overrides that don't affect desktop.
- **Format painter**: copy formatting from one visual and apply to others.

### 6.3 Insert menu
KPI card · Multi-card · KPI vs goal · Gauge · Chart (opens mini gallery with thumbnails) · Table · Matrix · Slicer (all types §10.3) · Map · Text box (supports dynamic values e.g. `{Total revenue}`) · Image · Shape (rectangle, rounded, line, arrow) · Icon · Button (actions §10.8) · Page navigator · Bookmark navigator · Apply-all / Clear-all slicers buttons · AI visuals (Summary, Key drivers, Decomposition tree, Ask-a-question box) · Python visual (advanced) · Visual from "My visuals" library.

### 6.4 Build tab (data)
- **Fields list**: searchable, grouped by dataset/table, icons by type (Σ numeric, Aa text, 📅 date, 🌍 geo, ƒx calculated), date fields expandable into **Year › Quarter › Month › Day** hierarchy; user-defined hierarchies (drag a field onto another).
- **Field wells** (depend on visual): Category/X-axis · Values/Y-axis · Secondary Y · Legend · Small multiples · Tooltips · Target · Size · Details · Drill-through.
- Per value field: aggregation (Sum, Average, Count, Distinct count, Min, Max, Median, Std dev, First, Last), **Show value as** (% of grand total, % of column/row, running total, difference/% difference from previous, rank), rename for this visual, number format.
- **Auto-suggest visual type** while adding fields (date + measure → line; category + measure → bar sorted desc; single measure → card; 2 measures → scatter; geo + measure → map; 2 categories + measure → matrix/heatmap; stages → funnel), toggle off in settings.
- **Visual calculations** button: running total, moving average (n), % of parent/total, rank, difference vs previous, YoY % — computed on the visual's own rows, no formula knowledge needed (expression mode for power users).
- Filters on this visual (shortcut to Filters tab).

### 6.5 Format tab (per visual)
Search box at the top; collapsible sections; every section has "Reset to theme default".
- **General:** X/Y/W/H, padding, alt text, maintain aspect ratio.
- **Title / subtitle / divider:** text (supports dynamic values from filter context: "Revenue · Kenya · 2025"), font, size, weight, colour, alignment, wrap.
- **Tile:** background (colour, gradient, image, transparency), border (colour, width, radius 0–24), shadow (none/soft/medium, colour), header icons visibility.
- **Axes:** show, title, font, label rotation, min/max, log scale, invert, gridlines (style/colour/width), dual-axis alignment.
- **Legend:** show/auto, position (top/bottom/left/right, start/centre/end), font, marker shape.
- **Data labels:** show, position (inside end/outside/centre), units (Auto/K/M/B), decimals, background, show category/% for donuts.
- **Colours:** per series, per category, **"Colour by value" gradient**, theme good/neutral/bad colours, highlight colour.
- **Bars/columns:** width %, spacing, corner radius, overlap.
- **Lines/markers:** smooth/straight/step, width, marker shape/size, area fill & opacity, dashed series.
- **Donut/pie:** inner radius, slice spacing, centre label (total/selected), max slices + "Others".
- **Table/matrix:** grid, row banding, header style, totals/subtotals position, column widths, word wrap, **conditional formatting** (background colour scale, font colour rules, data bars, icons, URLs), sticky header, row/column headers expand/collapse.
- **Card/KPI:** value font size, label position, delta (vs previous period / vs target / custom measure), up=good or up=bad, sparkline (type, period), icon/image, accent colour.
- **Analytics:** constant line, average/median/min/max/percentile lines, trend line, **forecast** (horizon, confidence band, seasonality), anomaly markers, error bars, target line — each with label & style.
- **Tooltip:** default / custom fields / **report-page tooltip** (pick a tooltip page).
- **Interactions:** default filter vs highlight behaviour of this visual.
- **Personalization:** allow viewers to personalize this visual (on/off).

### 6.6 On-object editing
- Double-click a visual (or right-click → Format) to enter format mode; hover highlights sub-elements (title, axis, legend, a series, a data label, a bar); clicking one opens that exact Format section.
- **Floating mini toolbar** above the selected visual: change type (thumbnail picker), colour, sort, data labels toggle, legend toggle, "More formatting".
- Inline rename of the title by typing on it.
- **Format several visuals at once** when multi-selected (shared properties only).

### 6.7 Visual header (hover; in edit and view mode)
Filter indicator (lists filters affecting the visual) · **Personalize ✎** (viewer) · Focus mode ⤢ · Drill up ↑ / drill down ↓ / go to next level ⇊ / expand all ⇉ · Sort ▾ · ⋯ menu: Show as table, Export data (CSV/Excel), Copy as image, Spotlight, Duplicate, Pin to another dashboard, Reset this visual, Remove.

## 7. Visual catalogue, KPI cards and chart defaults

### 7.1 Visual types required (map the 85-chart gallery to these families)
Comparison: bar, column, clustered, stacked, 100 % stacked, lollipop, dot plot, dumbbell, bullet/target, Pareto, radar · Trends: line, area, stacked area, combo (bar+line, dual axis), ribbon, step, moving average, sparkline, calendar heatmap · Composition: donut, pie (≤ 8 slices), treemap, sunburst, waterfall, funnel, Sankey · Distribution: histogram, box plot, violin, density · Relationship: scatter, bubble, correlation heatmap, PCA map · Maps: choropleth (Africa + world, region names like Uganda, Kenya, Nigeria, Egypt, South Africa must match), bubble map · Tables: table, matrix (pivot), heatmap table · KPIs: card, multi-card, KPI vs goal, gauge, half-donut gauge, progress bar, scorecard · AI: decomposition tree, key drivers, summary, anomaly · Model evaluation (keep existing): confusion matrix, ROC, residuals, feature importance, forecast vs actual.

### 7.2 KPI card component (most important visual)
- Anatomy: icon (optional, in a tinted circle) · **label** (12 px muted) · **value** (28–36 px bold, abbreviated: 5.2M, 16.9 %, 1.6K) · **delta chip** (▲ 12.4 % green / ▼ 3.1 % red; symbol + colour, never colour alone) · comparison text ("vs last month", ≤ 3 words) · optional **sparkline / mini bars** at the bottom · optional **target progress bar**.
- Styles user can pick: **Plain tile**, **Solid colour tile** (white text, like R1), **Gradient tile**, **Outlined**, **Icon-left**.
- Variants: single value, value + target, value + sparkline, multi-card (several values in one tile, like R3 "Financial analysis"), gauge.
- Responsive: value font scales with tile size; never wraps; never overflows.

### 7.3 Chart defaults (fixes S17)
- Chart engine: keep the current library only if it supports everything here; otherwise use **Apache ECharts** behind one adapter `<VisualRenderer type spec theme size />` so all types share formatting, theming, cross-filter events and export.
- Plot area fills the tile; **bar thickness 55–70 % of band**, max 48 px; when few bars, the tile can shrink — never giant empty space.
- Category labels always visible (truncate with ellipsis + tooltip, rotate only if needed; switch to horizontal bars when labels are long).
- Sort categorical bars **descending by value** by default; dates always chronological.
- **> 12 categories → Top N + "Others"** with toggle.
- Data labels: on by default when ≤ 8 bars or for donuts; off for dense charts (Microsoft tip: remove unnecessary labels).
- Numbers: max 3–4 significant digits, K/M/B scaling ("3.4M" not "3,400,000"), consistent decimals per field.
- Gridlines: horizontal only, very light; no chart borders; rounded bar ends 3 px; line width 2 px; area fill 12–18 % opacity.
- Legend auto-hidden for single series; placed top-right otherwise (as in R1).
- Donut: ≤ 6 slices + Others, labels outside "Name · 23 %", centre shows total or selected value.
- Consistent colour per category across all visuals on a dashboard (Online is always the same colour everywhere).
- Consistent scales and time frames across visuals on the same page.
- Empty / loading / error states inside the tile: skeleton shimmer, "No data for current filters — Clear filters" button, error with retry.

## 8. Themes and look & feel (user-chosen)

- **Theme JSON** model (§4) compatible in spirit with Power BI themes. Applying a theme restyles the whole dashboard instantly; per-visual Format overrides win over the theme.

## 9. "Play with the data" — data preparation for the best datasets (Data tab)

Keep everything that exists, upgrade to a Power Query-like experience:
- **Grid header** shows type icon + **column quality bar** (valid / error / empty %) + **mini distribution** (distinct / unique) — toggleable.

## 17. Backend / API

- `POST /api/visualize/query` — body `{datasetId, groupBy[], measures[{field, agg, showValueAs}], filters[], crossFilters[], sort, topN, visualCalcs[], parameters{}}` → aggregated rows + totals + metadata. Implemented with pandas (consider **DuckDB** for speed on larger files). **Cache** by query hash, invalidate on dataset change. Never return more rows than needed (cap 10k; tables paginate server-side).
- `POST /api/visualize/query/batch` — all visuals of a page in one round-trip.
- `GET/POST/PATCH/DELETE /api/dashboards`, `/api/dashboards/:id/versions`, `/api/dashboards/:id/personal-view`, `/api/themes`, `/api/visuals/library`.
- `POST /api/visualize/explain` (contributors to change), `/api/visualize/anomalies`, `/api/visualize/forecast` (reuse Predict code).
- `POST /api/ai/dashboard-page`, `/api/ai/suggest-visuals`, `/api/ai/summary` — return JSON specs validated with a schema (pydantic / zod).
- `POST /api/dashboards/:id/export` (pdf/png/xlsx/html/json) — headless browser render for PDF/PNG.
- Permissions on every endpoint (owner / editor / viewer); row limits per billing plan if applicable.

## 19. Don'ts
